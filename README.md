# WCX

一款基于 Xposed 框架的开源微信增强模块，提供丰富的功能定制与隐私防护能力。

## ✨ 功能特性

### 🎨 美化主题
- **Tab 主题背景**：为微信主页、通讯录、发现、我四个界面分别设置背景图片
- **主题导入导出**：支持主题包的导入导出，方便分享和备份
- **自定义配色**：个性化界面颜色方案

### 💬 聊天增强
- **进退群提示**：监控群成员进退群，自动发送自定义消息（支持文字、图片、语音、视频、文件）
- **AI 自动回复**：支持多种触发模式（仅被@、关键词、所有消息），可选择特定群聊开启
- **定时发送消息**：支持单次或每日重复发送，兼容多种消息类型
- **已读追踪**：本地Hook实现，不依赖服务器查看群消息已读人数
- **解除表情上限**：突破微信自定义表情999个上限限制

### 🔒 隐私防护
- **反检测/防追踪**：保护隐私，防止被检测
- **广告拦截**：屏蔽微信内广告

### 💳 支付相关
- **自动抢红包/接收转账**：收到红包或转账时自动处理
- **自定义回复**：支持文字、图片、语音等多种回复类型

### 📱 其他功能
- **聊天记录导出**：支持多种格式导出
- **短视频下载**：下载朋友圈短视频
- **脚本支持**：支持 JavaScript 和 Java 脚本扩展

## 🏗️ 项目结构

```
wcx/
├── deobf/          # 微信模块去混淆分析工具 (unidbg 脱壳/解密)
├── app/            # Xposed 模块主程序
├── buildSrc/       # Gradle 构建配置
├── xtask/          # Rust 构建任务
├── docs/           # 文档
├── scripts/        # 辅助脚本
├── icons/          # 图标资源
└── libs/           # 依赖库
```

## 📦 子项目

### deobf — 去混淆分析工具

基于 unidbg ARM64 模拟器的动态解密与去混淆框架，用于分析微信模块的加密载荷。

### app — Xposed 模块

适用于微信的 Xposed 模块，提供功能增强与定制化能力。

## 📋 适配版本

- 微信版本：8.0.43 - 后续自适应（不含测试版）
- 框架支持：LSPosed、EdXposed、Xposed
